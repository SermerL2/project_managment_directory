# Project Management Directory

This repository stores project-management and educational materials related to coursework, semester projects, and practical training documentation.

It contains both archived project files and newer template documents used for course work and project planning.

## Repository structure

- `archive/` — archived materials and historical project documents
  - Methodological guidance for semester project preparation
  - Communication scheme documents
  - Project planning and scheduling files
  - Draw.io diagrams and diagrams related to coursework
- `new/` — newer template and working materials
  - Practical lessons template document

## Included file types

The repository mainly contains:

- `.docx` documents
- `.pptx` presentations
- `.drawio` diagrams
- `.mpp` Microsoft Project files

## Purpose

This project acts as a document repository for:

- semester project preparation
- project management training
- communication and architecture documentation
- practical study materials
- schedule and planning resources

## Notes

- Some files are in Russian, reflecting the educational context and source documents.
- This repository is documentation-focused rather than code-focused.
- Files are intended for viewing/editing in Microsoft Office, draw.io, or Microsoft Project-compatible tools.

## Suggested tools

- Microsoft Word for `.docx` files
- Microsoft PowerPoint for `.pptx` files
- draw.io for `.drawio` files
- Microsoft Project for `.mpp` files

## Typical use

Open the relevant files in the `archive/` folder for historical coursework materials, or use the files in `new/` as updated templates for ongoing work.
